# Cloud Compute

## Login to Cloud

The Cloud environment is designed with **secure access by default**.

- Legal and Technical Owners can request changes to the security configuration by contacting Computerome.

You can download and install Omnissa Horizon Client by going to
[https://vdi.computerome.dk](https://vdi.computerome.dk) and clicking on
**Install Horizon Client**.

### Default Access Method

1. Use the **Omnissa Horizon Client**.
2. After login, you will see one **icon per project** you are a member of.
3. Clicking a project icon opens a graphical Linux environment.
4. From there, you can open a terminal and **SSH into your cloud VM**.

### If Your Cloud Has a Queueing System

- You only need to **SSH to the login node of your queueing system from Horizon**.
- Please contact your **Cloud Legal/Technical Owner** to find out the correct login host.

## Scaling Your Cloud Project

As the **Legal** or **Technical Owner** of a Cloud project, you can scale your environment at any time. This includes:

- Adding new virtual machines (VMs)
- Removing existing VMs
- Scaling VMs up or down (adjusting resources)

To manage resources:

1. Go to **My Solutions > Cloud > Projects > [your project]**.
2. Open the **Resources** tab.
