# Getting Started

At **Computerome**, you may be a **Cloud user**, a **HPC user**, or both.

If you are unsure which type of user you are:

1. Go to our [**Sign In page**](https://computerome.dk) and log in.
2. Click on **My Solutions**.
3. You will see the following menus:
    - **Cloud menu** → You can see the cloud projects that you are a member of by clicking on this menu.
    - **HPC menu** → You can see the HPC projects that you are a member of by clicking on this menu.

!!! note

    You may have multiple usernames with Computerome. For example, one username may be used for Cloud, and another for HPC.

---

## User Types at Computerome

There are **three main user types**:

<div class="grid cards" markdown>

-   :lucide-user:{ .lg .middle } **Normal User**

    ---

    A member of an HPC or Cloud project with limited access, primarily to run
    tools and perform daily work.

-   :lucide-scale:{ .lg .middle } **Legal Owner**

    ---

    The legally responsible person for one or more HPC or Cloud projects.

    - Decides who gets access.
    - Acts as the **contact point** for Computerome regarding the project.
    - Serves as the **billing contact**.

-   :lucide-wrench:{ .lg .middle } **Technical Owner**

    ---

    The technical administrator of one or more HPC or Cloud projects.

    - Same responsibilities as the Legal Owner.
    - **Exception:** not the billing contact.

</div>

!!! note

    For each project, one user is also designated as the **Security Contact** (often the Legal or Technical Owner). This person is our point of contact in case of security incidents.
